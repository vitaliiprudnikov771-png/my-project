# GROUND ZERO\n\nAtmospheric first-person survival maze prototype for mobile and desktop.\n\n## Foundation\n- Modular Three.js scene and maze environment\n- FPS camera and touch/keyboard movement and look\n- Camera-mounted weapon presentation and flashlight\n- Monster AI pursuit prototype\n- HUD, ammo/reload, health and session states\n- Telegram Mini App initialization\n\n## Modules\n`main.js` orchestration; `maze.js` environment; `player.js` camera equipment; `monster.js` creatures; `audio.js` effects.\n\nMultiplayer/server-authoritative logic is planned but not implemented.
